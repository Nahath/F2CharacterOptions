This is a mod for Fallout 2 with the following changes:

1. Allow power armor to increase strength above 10 (nothing else will take it above 10. Just power armor)
2. If stealing skill is greater than 60, you can steal characters' weapons even if they are actively equipped
3. Add an item "Dynamite MKII" which works like normal dynamite except does double damage. Also has double value in barter. Use the same icon but slightly darker. This can be purchased from the bartender at "The Golden Gecko" in Klamath.
4. Goris can wear the Bridgekeeper's Robes but no other armor
